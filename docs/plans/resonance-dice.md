# 共鸣骰

金边紫晶骰子配环绕箭头，图标使用 SVG 接入现有图标注册和预加载流程。普通商店 15 金币，无尽商店基础价 25，阶段涨价沿用现有规则。

玩家行动阶段且当前手牌已有共鸣时使用。均匀随机选择另一个当前牌型能组成的点数，再随机选择对应牌面变换；保留共鸣类别、倍率和牌数。同点数共鸣牌一起换点，同花共鸣通常点化其中一张牌；双王可以点化一张。普通共鸣、强共鸣及三/四张炸弹均保留类别。同点数两张/四张等牌型的可用点数受真实牌值限制，不能保证所有 0–9 点都可出现。

不改变阶段、技能冷却、摸牌次数、锁牌或伤害惩罚。普通模式沿用总计三次道具限制，无尽不限整局次数。使用失败不消耗道具。使用时骰子旋转、旧牌聚集后展示新牌，并浮出点数前后对照。

无尽购买、随机状态和消耗采用现有同步事务保存；失败回滚手牌、库存和 RNG。旧商店快照缺少第五种商品时可恢复，共鸣骰库存按 0 处理，下一次商店才上架。

验证：109 项自动测试及构建通过。浏览器验证普通商店购买、五件商品布局、图标加载、无尽局内购买与使用、一次消耗以及刷新恢复，无页面异常或资源缺失。截图和报告位于 tmp/resonance-dice，回归脚本 scripts/qa/resonance-dice-browser.cjs。
