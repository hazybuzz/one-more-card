# Edo Teahouse / 江户茶屋

## 目标

江户茶屋是第四张正式牌桌，也是第一张以“可见威胁、延迟反制、判断出手窗口”为核心的高挑战牌桌。

它不增加新的玩家基础规则。玩家仍使用现有的主动技能、道具、第二次再来一张和共鸣系统；敌人的被动则要求玩家不能只盯着当轮点数。

主题体验：

- 幕府武士惩罚无脑邀请。
- 忍者让关键强共鸣不能随意交给残血目标。
- 花魁会把本轮失血变成下一轮的队伍收益。

### 幕府武士：居合蓄势

定位：前排反击，激励玩家判断邀请的风险。

- 当武士拒绝“邀请再来一张”时，获得 1 层居合，最多 2 层。
- 居合层数跨回合保留。
- 武士下一次比牌获胜时，额外造成等同层数的伤害，然后清空层数。
- 武士输掉比牌时不消耗居合；玩家仍需面对未释放的威胁。
- 武士被击败时，居合失效。

建议 AI：点数越高越倾向拒绝。

| 当前点数 | 接受邀请倾向 |
| --- | --- |
| 0-3 | 高 |
| 4-6 | 中等 |
| 7-8 | 低 |
| 9 | 极低 |

### 忍者：替身烟幕

定位：残局规避，制造需要先处理的攻击窗口。

- 当忍者 HP 小于 3，且本局尚未触发过替身时，在回合开始时进入“烟幕待命”。
- 烟幕待命期间，忍者下一次受到的伤害全部规避；该次攻击仍播放命中动画，但不扣 HP。
- 烟幕触发后永久失效，不会再次进入待命。
- 忍者在待命前已被击败，则不会触发。

该技能是一次性完整规避，不与伤害减免叠加。它的存在要迫使玩家先观察忍者面板上的烟幕状态，再决定是否交出关键共鸣。

### 花魁：花宴之舞

定位：延迟支援，把玩家本轮受伤转为下一轮的压力。

- 每回合开始，花魁从“其他存活闲家”中随机选择一名，挂上舞扇标记。
- 本轮累计记录玩家受到的实际敌方伤害总和。
- 下一回合开始时，若舞扇目标仍存活且本轮累计伤害大于 0，则随机结算一种回响：
  - 恢复 `min(累计伤害, 2)` HP；或
  - 获得本轮 `攻击 +min(累计伤害, 2)`。
- 攻击加成只在该回合生效；回血正常保留。
- 若玩家本轮未受伤，舞扇自然消散，无收益。
- 若目标在结算前已被击败，舞扇与累计伤害一并消散，不转移。
- 场上只剩花魁时，不会挂舞扇。

攻击与回血结果直到下一回合开始才揭晓。玩家在本轮知道自己欠下了“花宴”的账，但不知道花魁会选择续命还是强化攻击。

## 新增状态

在 `EnemyState` 中增加：

```ts
iaijutsuStacks: number;        // 武士：0-2，跨回合保留
smokeScreenArmed: boolean;     // 忍者：当前是否处于烟幕待命
smokeScreenUsed: boolean;      // 忍者：本局是否已触发替身
hanamiFanTargetId?: EnemyId;   // 花魁：当前舞扇目标
hanamiDamageBank: number;      // 花魁：本轮累计的玩家实际受伤量
```

`roundAttackBonus` 已经适合承载花宴的“攻击 +1 / +2”，不需要另建临时攻击字段。

## 回合与事件顺序

### 回合开始

1. 清空所有敌人的 `roundAttackBonus` 与本回合标记。
2. 结算上一回合的花宴回响：先检查舞扇目标是否存活，再随机回血或增加本回合攻击。
3. 清空旧舞扇目标与伤害储量。
4. 检查忍者是否进入烟幕待命。
5. 花魁为新的其他存活闲家挂舞扇。
6. 发放本回合手牌。

花宴回响必须在新舞扇挂载前结算，避免一个目标同时带两份状态。

### 邀请阶段

1. 玩家邀请幕府武士。
2. 若武士拒绝，立即获得一层居合并发出事件。
3. 继续现有的敌方接受/拒绝流程。

### 比牌与伤害阶段

1. 武士获胜时，将 `iaijutsuStacks` 加入本次敌方伤害并清空层数。
2. 忍者受到伤害且烟幕待命时，生成规避事件，伤害记为 0，清除烟幕。
3. 玩家受到每次实际敌方伤害时，若舞扇目标仍有效，累加到 `hanamiDamageBank`。
4. 保留现有逐次攻击、逐次扣血、击败和回血流程。

## 引擎事件设计

扩展 `BattlePresentationEvent`：

```ts
// passive-effect 新增 passiveId
'iaijutsu_charge' | 'smoke_substitution' | 'hanami_dance'

// passive-effect 新增 effect
'charge' | 'arm' | 'evade' | 'mark' | 'reward_attack' | 'reward_heal'

// damage 事件新增可选标记
evaded?: boolean;
```

事件语义：

| 时机 | 事件 | 关键数据 |
| --- | --- | --- |
| 武士拒绝 | `iaijutsu_charge / charge` | 武士、当前层数 |
| 忍者待命 | `smoke_substitution / arm` | 忍者 |
| 忍者规避 | `damage`，`amount: 0`，`evaded: true` | 忍者、原始伤害 |
| 花魁挂扇 | `hanami_dance / mark` | 花魁、目标 |
| 花宴回血 | `hanami_dance / reward_heal` | 花魁、目标、实际数值 |
| 花宴加攻 | `hanami_dance / reward_attack` | 花魁、目标、实际数值 |

## Scene 表现规范

### 居合蓄势

- 武士框旁常驻 `居合 x1/x2` 红金标记。
- 拒绝时：收刀姿态、刀鞘红金闪光、短促金属音。
- 释放时：标记碎裂，快速拔刀斩；伤害浮字显示最终值。

### 替身烟幕

- 待命时：忍者框边缘有低密度紫灰烟雾与“烟幕”标签。
- 触发时：攻击落入烟雾，忍者短暂消失，木偶/残影落地，显示“规避”。
- 不显示 `-0 HP`，不播放受伤爆炸音。

### 花宴之舞

- 挂扇：粉金折扇由花魁飞向目标，飘带连接两者；目标旁显示“舞扇”。
- 回响：下一回合先播放飘带收紧，再揭晓 `HP +N` 或 `攻击 +N`。
- 攻击加成使用现有 `攻击 +N` 标签，确保之后任何来源的攻击加成共用同一套表现。

## 开发顺序

1. 扩展主题、敌人、状态类型与中英文文案；确保现有主题编译不受影响。
2. 实现居合蓄势及其伤害结算单元逻辑。
3. 实现忍者烟幕与 `evaded` 伤害事件，接入逐次攻击表现。
4. 实现花宴的跨回合储量、回合开始结算与临时攻击加成。
5. 为三个事件接入 BattleScene 的标签、动画、音效与日志。
6. 添加 `edo` 主题灰盒视觉，并在 1x/2x/3x 倍率下做完整战斗回归测试。

## 验收标准

- 玩家能在 UI 上提前看到居合层数、忍者烟幕和舞扇目标。
- 每个被动都会改变当轮或下一轮的真实决策，而不只是数字变化。
- 忍者规避不会扣血，也不会提前触发击败或结算。
- 花宴攻击加成在下一回合结束时清空，且不会跨回合叠加。
- 武士的居合最多 2 层，释放后清空。
- 不影响永夜酒馆、北境长屋、龙门赌坊及故事关卡。
