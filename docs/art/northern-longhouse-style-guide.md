# 北境长屋战斗美术规范

版本：1.0  
适用范围：北境长屋战斗背景、角色、技能图标、攻击效果和战斗 UI

## 1. 主题定位

北境长屋的视觉关键词：

> 冷铁、焦木、冰蓝符文、炉火、风雪、粗粝荣耀。

它与永夜酒馆共用战斗布局和交互语言，但不直接复制永夜酒馆的棕金材质。北境应通过冷蓝金属、深色木材与少量炉火橙形成冷暖对比。

视觉优先级保持一致：

1. 扑克牌与点数
2. 当前行动角色与技能触发
3. HP、增益和伤害反馈
4. 角色立绘与主题装饰
5. 背景环境

## 3. 色板

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨黑 | `#11151B` | 最深轮廓、UI 内底 |
| 焦木 | `#29231F` | 木材、面板暗部 |
| 冷铁 | `#667785` | 框体与金属主体 |
| 符文蓝 | `#58B8E8` | 可用状态、主题强调 |
| 霜蓝 | `#A8D8E8` | 高光、施法核心 |
| 炉火橙 | `#C56A35` | 少量暖光、受击火星 |

符文蓝是主题识别色，但不能覆盖整张界面。背景与框体以墨黑、焦木、冷铁为主，蓝色只用于边缘、高光和关键状态。

## 4. 角色动作套图

### 4.1 通用规格

- 每张套图为 `2×2` 四帧，单帧 `128×128`，总尺寸 `256×256`。
- 帧顺序固定：左上 `0 待机` / 右上 `1 施法` / 左下 `2 攻击` / 右下 `3 受伤`。
- 透明背景，不画角色框、地面、桌子、文字和 UI 光效。
- 四帧头部基准线与躯干中心必须稳定，动作不能产生明显跳位。
- 所有武器、头盔和关键轮廓保留在安全区内。
- 写实暗黑像素风，光影与永夜酒馆重制角色保持同一精细度。

### 4.2 朝向

| 角色 | 席位 | 主要朝向 |
| --- | --- | --- |
| 维京战士 | 左侧 | 朝右，面向牌桌中央 |
| 符文萨满 | 上方 | 正面，施法与攻击朝下 |
| 女武神 | 右侧 | 朝左，面向牌桌中央 |
| 英灵 | 被召唤席位 | 近正面，攻击方向由运行时动效补足 |

### 4.3 角色辨识重点

- 维京战士：红发、冷铁头盔、双短斧、厚重前压动作。
- 符文萨满：白发、熊皮、木杖、冰蓝符文光。
- 女武神：银翼头盔、橙发、长矛、召唤姿态。
- 英灵：蓝色半透明战魂、短剑与盾，但角色主体本身保持足够不透明，透明感由运行时着色控制。

## 5. 被动技能图标

遵循 `docs/art/icon-style-guide.md`，使用 `128×128` 透明 PNG，并以 `48px` 实际显示尺寸验收。

| 技能 | 主体 | 强调色 |
| --- | --- | --- |
| 战争号角 | 粗粝骨角与向外声浪 | 炉火橙、暗红 |
| 符文祝福 | 发光符石与向上的祝福纹 | 符文蓝、霜蓝 |
| 英灵召唤 | 盾后升起的灵魂战士 | 霜蓝、骨白 |

图标只表达技能身份。旋转、波纹、角色施法动作、目标连线和数值变化由 Phaser 实现。

## 6. 攻击素材

- 每名可攻击角色只制作一张透明或 chroma 核心素材。
- 推荐母版 `128×128`，主体占安全区的 `65%-78%`。
- 普通、共鸣和强共鸣不制作重复图片，由运行时调整尺寸、亮度、尾迹数量和命中粒子。
- 素材不得内置长尾迹，避免旋转和缩放时失真；尾迹由 Phaser 绘制。

| 角色 | 核心素材 | 运行时色彩 |
| --- | --- | --- |
| 维京战士 | 冷铁短斧 | 冷铁蓝，命中带橙色火星 |
| 符文萨满 | 冰蓝符文弹 | 符文蓝与霜白 |
| 女武神 | 发光长矛尖 | 银蓝与少量暖金 |
| 英灵 | 幽灵短剑 | 苍蓝与冷白 |

## 7. UI 材质

### 7.1 圆形角色框

- 创作母版 `512×512`，运行时资源可压缩至 `256×256`。
- 中央完全透明，边框视觉厚度不超过画布宽度的 `8%`。
- 材质为深色焦木与冷铁包边，刻少量冰蓝符文。
- 不把选中光、呼吸光和状态颜色画进图片，由运行时统一处理。

### 7.2 按钮

- 与永夜酒馆保持相同外形比例、九宫格切片和点击区域。
- 材质改为焦木内底、冷铁边框、少量蓝色符文铆钉。
- 默认文字使用骨白；悬浮使用霜蓝；危险操作保留全局暗红语义。
- 不在图片中写文字。

### 7.3 弹窗与 Tooltip

- 弹窗与按钮属于同一材质家族，均使用九宫格资源。
- Modal 边框可以比 Tooltip 厚，但不得使用大面积蓝色发光。
- Tooltip 内底接近墨黑，保证中英文说明清晰易读。

## 8. 动效原则

- 被动触发总时长建议 `1.4-2.2s`，保证玩家看清触发者、目标和结果。
- 顺序固定为：角色施法 → 技能身份 → 目标连线/落点 → HP 或攻击变化 → 回到流程。
- 战争号角强调横向声浪；符文祝福强调目标连接；英灵召唤强调空席位凝聚。
- 不让发牌、攻击和被动动画并行修改同一角色状态。
- 增益标签与数值变化必须在视觉落点后出现。

## 9. 验收清单

- 四名角色在实际圆框尺寸下头部、武器和动作清晰。
- 四帧切换时角色中心不跳动。
- 三个被动图标在 `48px` 下不看文字也能区分。
- 普通、共鸣、强共鸣攻击只靠运行时强化也有清楚层级。
- 按钮、Modal、Tooltip 不再回退到灰盒样式。
- 战争号角、符文祝福、英灵召唤不会与发牌或下一轮动画重叠。
- 英灵被召唤后角色、攻击和受击表现不发生画风断层。
- 简单、普通、困难三档均完成一次完整战斗验证。
